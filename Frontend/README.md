# OccazCar - Plateforme de voitures d'occasion

## À propos du projet

**OccazCar** est une plateforme moderne pour l'achat et la vente de voitures d'occasion en toute sécurité.

## Comment modifier ce code ?

Il y a plusieurs façons de modifier votre application.

**Utiliser votre IDE préféré**

Si vous voulez travailler localement avec votre propre IDE, vous pouvez cloner ce repo et pousser les changements.

La seule exigence est d'avoir Node.js & npm installés - [installer avec nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

Suivez ces étapes :

```sh
# Étape 1: Cloner le repository en utilisant l'URL Git du projet.
git clone <YOUR_GIT_URL>

# Étape 2: Naviguer vers le répertoire du projet.
cd occazcar-web-wheelhouse-main

# Étape 3: Installer les dépendances nécessaires.
npm i

# Étape 4: Démarrer le serveur de développement avec rechargement automatique.
npm run dev
```

**Éditer un fichier directement dans GitHub**

- Naviguer vers le(s) fichier(s) désiré(s).
- Cliquer sur le bouton "Edit" (icône crayon) en haut à droite de la vue du fichier.
- Faire vos modifications et commiter les changements.

**Utiliser GitHub Codespaces**

- Naviguer vers la page principale de votre repository.
- Cliquer sur le bouton "Code" (bouton vert) en haut à droite.
- Sélectionner l'onglet "Codespaces".
- Cliquer sur "New codespace" pour lancer un nouvel environnement Codespace.
- Éditer les fichiers directement dans le Codespace et commiter et pousser vos changements une fois terminé.

## Quelles technologies sont utilisées pour ce projet ?

Ce projet est construit avec :

- **Vite** - Build tool rapide et moderne
- **TypeScript** - Langage de programmation typé
- **React** - Bibliothèque UI
- **shadcn-ui** - Composants UI modernes
- **Tailwind CSS** - Framework CSS utilitaire
- **React Router** - Routage côté client
- **Lucide React** - Icônes modernes

## Comment déployer ce projet ?

Pour déployer OccazCar :

1. **Build de production** : `npm run build`
2. **Preview local** : `npm run preview`
3. **Déploiement** : Utilisez votre plateforme de déploiement préférée (Vercel, Netlify, etc.)
